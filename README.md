# Chelsia Joy — Interactive Resume

A horizontal, responsive resume page built with HTML, CSS, JavaScript, and p5.js. It includes color themes, an interactive experience timeline, role filters, and expandable job details. No build step or package installation is required.

## Deploy with Netlify

Import this repository (`chelsiajoy-gif/ResumeCHELSIA`) into Netlify and use:

- **Build command:** leave blank
- **Publish directory:** `.`

The included `netlify.toml` sets the publish directory. p5.js loads from jsDelivr, so the deployed browser needs internet access for the animated background.

## Before publishing

- This GitHub repository is public. The resume page includes the phone number and email from the CV, so they are publicly visible in the repository and on any deployed site.
- The CV lists the Bachelor of Education as “Pursuing” for 2023–2025; confirm its current status before using the resume.
- The CV did not include a LinkedIn URL, so none is shown.
